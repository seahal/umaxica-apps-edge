# ADR 025: Who owns CSP violation reports

## Status: Accepted 2026-10-06 — contract only, nothing implemented

## Context

Every Edge unit sends a `Content-Security-Policy`. None of them sends a
`report-uri`, a `report-to` or a `Reporting-Endpoints` header, and no Edge unit
answers a report endpoint. The only trace of reporting in Edge today is a route
label: `/csp-violation-report` is classified as `csp_report` in each frame's
`src/lib/request-log.ts`, and in the Cores' `src/lib/rails-dispatch-log.ts`,
where the path is Rails-owned and relayed.

Reporting will be added. Before it is, the ownership has to be written down,
because the two families differ and the difference is easy to get wrong later:
the Cores share their hostname with Rails (ADR 007), the other units do not.

This record decides ownership. It does not add an endpoint, a directive or a
header.

## Decision

### Core: Rails owns the report URL

On a Core hostname the browser-facing CSP report URL belongs to Rails. A
policy generated by Edge on that hostname therefore reports to Rails: Rails
accepts Edge-generated reports on Edge's behalf.

Rails then receives reports for two different policies on one hostname — its
own, and the one Edge stamped on the documents Edge renders. They must stay
distinguishable afterwards, permanently and reliably.

**The distinction is a trusted, server-side classification.** Rails assigns it
as a fixed value from context it controls: which route, and so which
controller action, the report arrived at. The Edge-generated policy names a
report URL that only an Edge-generated policy names; arriving there is what
makes a report an Edge report.

**Nothing in the report body is trusted for this.** A CSP report is sent by a
browser and is fully attacker-controllable: `document-uri`, `blocked-uri`,
`original-policy`, the disposition, and any field that looks like it states who
wrote the policy. None of them may decide, or influence, the classification.
They are payload, recorded as received.

The shape is one value per owner, for example:

```text
policy_owner = edge
policy_owner = rails
```

**The field name is not decided here.** `policy_owner` above is an
illustration, not a contract. The name has to agree with Rails' existing CSP
telemetry schema, and that schema could not be read when this record was
written — the Rails repository was not accessible from this workspace. Whoever
implements this reads the schema first and chooses a name consistent with it;
if the schema already has a field that carries this meaning, that field is
used rather than a second one added.

### Everything except Core: Edge owns the endpoint

For every unit that does not share a hostname with Rails — the twelve public
content cells, the apex Workers, and any later surface Edge can own outright —
the report endpoint will be Edge's own, on the unit's own origin.

### Not part of this decision

- **Workers VPC.** Report ownership has nothing to do with the VPC transport.
  A browser posts a report to a public URL; no private path is involved, and
  nothing here should be read as a reason to route reports through one.
- **Trusted Types.** No `require-trusted-types-for` enforcement is introduced.
- **An endpoint.** No Edge unit gains a route, and no policy gains a reporting
  directive.

## Consequences

- When reporting is implemented for Core, the Edge-side change is a directive
  naming a Rails URL, and the Rails-side change is a route that classifies.
  Neither side parses the other's reports to find out whose they are.
- A report forged against the Rails route can lie about everything except
  which route it was sent to. That is the property the classification rests on.
- Edge-owned endpoints will be new, attacker-reachable POST surfaces. They come
  under the existing first-touch limiter (ADR 010) and body limit like any
  other route; that design is deferred with the endpoint itself.

## Outcome

Implementation deferred. This record fixes ownership and the trust rule for
classification only. Open item carried forward: the classification field name,
to be settled against the Rails CSP telemetry schema at implementation time.
